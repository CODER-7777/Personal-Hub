# Personal Hub v2.5.0 — Reliable Sync, Schedule Editing & New Branding

This release improves how your Hub stays consistent across devices, adds timetable editing for phones and tablets, and applies the new Personal Hub logo across platforms.

## New and improved

- **Edit your timetable:** change class name, day, start/end time and room using visible touch-friendly controls. Weekend columns, overlap warnings, time validation and deletion confirmation make schedule changes easier.
- **New branding:** updated app UI, favicon, PWA icons, Android launcher assets and desktop icons. Added Linux packaging icon configuration and Windows application identity. The original logo is preserved outside the build output, with repeatable icon generation.
- **Simpler signup:** create an account with your name, email and password. Add an optional Codeforces handle and avatar in Settings.
- **Shared account profile:** name, avatar and Codeforces handle now load and update through the same account profile across clients.
- **Visible sync status:** Settings shows queued changes and errors, with a retry action that sends pending edits.

## Reliability fixes

- Replaced whole-collection uploads with transactional record/field merges so one device's additions do not discard another device's work.
- Added a persistent, account-specific outbox to replay offline changes after reconnecting or restarting.
- Prevented stale cloud snapshots and late acknowledgements from rolling back newer state.
- Guarded account switching and delayed AI imports against writing into another user's Hub.
- Preserved older caches with unknown account ownership for manual recovery rather than automatically uploading them into the next account.
- Added finance archives and profile metadata to backups; disabled the destructive automatic monthly transaction reset.
- Awaited receipt/timetable processing correctly and validated extracted data before saving it.
- Removed duplicate PWA manifests and repaired missing icon references.

## Security changes

- Updated Capacitor Android/core/CLI to **8.5.2** to address the Android origin/proxy vulnerability. Installed Android apps need the rebuilt APK to receive this fix.
- Disabled Electron renderer Node integration, restricted navigation to the app's exact origin, validated external HTTP(S) links and blocked webviews.
- Tightened desktop script CSP and removed the unsafe HTML debug error sink.
- Removed embedded/persisted Gemini keys. The optional Settings key is held only for the current session and must be entered again after restarting.
- Disabled Android app backup and removed push registration-token logging.
- Corrected privacy and account-deletion disclosures.

## Upgrade notes

1. Export a backup on each device before upgrading or clearing app storage.
2. Update all active clients and sign into the same account. Older versions can still overwrite entire cloud collections.
3. Check **Settings → Account sync** after reconnecting. Do not clear storage while changes are pending.
4. If older offline records appear missing, preserve the `personal-hub-legacy-recovery` entry before clearing storage and consult the audit's recovery instructions.

Version metadata is aligned to **2.5.0** across web and desktop; Android uses **versionCode 20500**.

## Validation and known limitations

The 17 regression tests, root/Electron TypeScript checks, production web build and Capacitor web-asset synchronization passed locally. Interactive native-device and installer testing was not completed. CI builds downloadable assets separately; assets are attached after the platform builds succeed.

This is not a complete security remediation. Old Electron/packaging dependencies and additional dependency advisories remain. Electron's legacy preload still requires `sandbox: false`. Simultaneous edits to the same field can overwrite each other; goal increments and notification cancellation still need improvement. Delete Account currently removes the sign-in account but leaves cloud records.

The existing Android pipeline produces a **debug APK**, not a production-signed Android release. Signing identity can differ from previously installed builds; export your data before reinstalling. Google Calendar integration, backup restore and a complete push backend remain unavailable.

See [the detailed audit](https://github.com/CODER-7777/Personal-Hub/blob/v2.5.0/docs/PERSONAL_HUB_AUDIT.md) for remaining issues and recommended next steps.
